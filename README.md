STEPS OF CREATING A GRPC SERVER-CLIENT PROJECT  
Server Side: 

Create a new gRPC project (dotnet new grpc). 

Define the service in a .proto file.(The proto files contains the models or DTO's and the functions for making grpc calls) 

Implement the service in a C# class. 

Configure the server in Program.cs or Startup.cs. 

Run the server using dotnet run. 

Client Side: 

Create a new console application (dotnet new console). 

Install necessary gRPC client NuGet packages. 

Add the .proto file or generate client proxies using Grpc.Tools. 

Create a gRPC client and make requests to the server. 

Run the client using dotnet run.
